# Two Hairs / Liquid Bridge

A small, dependency-free research-sketch animation prototype for an AI × Education video.

## Run it

Open `index.html` directly in any modern browser. No build step or server is required.

## Files

- `config.js` — main timing, colors, labels, and layout values.
- `timeline.js` — the 15-second animation sequence.
- `styles.css` — paper, ink, and page styling.
- `index.html` — SVG scene and the page shell.

The animation loops through: **two hairs → attention on the gap → liquid bridge → transfer to substrate**.
